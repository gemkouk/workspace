# Intro Page for MSc in Statistics and Actuarial – Financial Mathematics

This is a responsive intro landing page for the Master's Programme in
**Statistics and Actuarial – Financial Mathematics** at the University of the Aegean.

## Features

- Full-screen academic-themed background
- Typing effect on bilingual titles (Greek / English)
- Soft ambient audio with fade-in
- Dual-language entry buttons (GR / EN)
- Auto-redirect to browser language after 7 seconds (if no interaction)
